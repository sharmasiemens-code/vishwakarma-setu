# Vishwakarma Setu identity

Original geometric artwork created for this change: two connected arches, a shared span and two endpoints. The bridge represents a connection between customers and skilled local professionals across trades, without choosing a single trade's tools.

- `icon.svg`: compact 48-unit mark, also used as the SVG favicon.
- `logo-light.svg`: wordmark for a light background.
- `logo-dark.svg`: wordmark for a dark background.
- `shared/Brand.jsx`: accessible inline application lockup.

The source SVGs contain no external images, scripts, fonts or service dependencies. The wordmark uses system fonts; convert text to outlines in a design tool only if a fixed print appearance is needed. Keep at least eight units of clear space around the compact icon. At very small sizes use only the icon. Teal `#123c47`, warm white `#fff9ed`, amber `#f4b45f`.

Public copies in each Vite app match these source assets. No trademark clearance or device-store submission has been performed.
