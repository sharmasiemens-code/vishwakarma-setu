\# Technical Expert Marketplace

\## MVP Project Plan



\### Project Objective



Build a local service marketplace connecting customers with verified

technical experts and skilled service professionals.



The initial pilot will operate in one local area and will later expand

to additional cities.



\---



\## Customer



A customer should be able to:



1\. Register/login

2\. Select a service category

3\. Select a specific service

4\. Describe the requirement

5\. Upload photographs

6\. Share location

7\. Submit a service request

8\. Find available verified experts nearby

9\. View expert profile

10\. View expertise and available tools

11\. View approximate distance

12\. Contact the expert

13\. Track job status

14\. Complete the service

15\. Give rating/review



\---



\## Technician / Expert



An expert should be able to:



1\. Login using credentials provided by the platform

2\. Maintain profile

3\. Submit KYC information

4\. Select expertise

5\. Select available tools

6\. Set service area

7\. Set Available / Offline status

8\. Share location when available

9\. Receive service requests

10\. Accept/reject requests

11\. Update job status

12\. Complete jobs

13\. View job history

14\. Receive ratings/reviews



\---



\## KYC



Technician verification will include:



\- Name

\- Mobile number

\- Email

\- Address

\- Photograph

\- Identity verification

\- Address verification

\- Professional information

\- Skills

\- Tools

\- Experience

\- Bank/payment information when required



Only approved technicians will become searchable by customers.



\---



\## Expert Matching



The system will match experts using:



\- Service category

\- Required skill

\- Required tools

\- KYC approval

\- Availability

\- Location

\- Service radius



Initial search radius:



10 KM

\## Development Principle



Build one module at a time.



Test every module before moving to the next module.



Do not build unnecessary features before validating the business model.



Initial focus:



Customer -> Requirement -> Nearby Verified Expert -> Contact -> Service -> Rating
